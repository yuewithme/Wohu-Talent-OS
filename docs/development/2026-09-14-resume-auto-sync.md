# BOSS 消息附件简历自动同步飞书

## 任务目标

按用户最新需求，打开 BOSS 后自动运行插件，识别消息中收到的附件简历并上传到指定飞书多维表格。建立 Git 仓库和功能分支，按可验证阶段提交。目标转为消息附件同步，不再以手动读取推荐候选人为本次交付中心。

## 实施计划

1. 保存 v0.2.1 Git 基线，在功能分支开发。
2. 核对真实消息事件、候选人身份、附件下载来源；确认自动处理范围和目标表结构。
3. 实现自动监听、持久化任务队列、幂等去重、附件上传及记录写入、有限重试、配置和状态展示。
4. 在授权范围内实测收到附件、同步成功、重复事件、重启与失败恢复；验证包并提交 Git。

## 完成标准

已配置后打开 BOSS 自动开始监听，收到简历后无需手动读取；同一消息附件只创建一次目标记录，表内附件可打开；失败原因和重试可见。真实简历、密钥、下载 URL 和本地运行数据不进入 Git。缺少目标表、认证或真实样本时如实标记未完成项。

## 完成结果与验证

实施中。目标表链接、应用和自动处理范围已向用户询问。
