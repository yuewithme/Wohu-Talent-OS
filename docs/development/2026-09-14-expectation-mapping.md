# 候选人求职期望映射修正

## 任务目标

修复用户截图中求职期望被归为平台推荐方向、可见状态未显示的问题。核对当前候选人的真实来源，保留当前公司与历史实习、当前城市与期望城市的区别。

## 实施计划

1. 检查当前页面详情运行时、DOM 标签和实际采集结果，定位映射错误。
2. 最小修正来源映射与证据，补充必要的针对性验证。
3. 在同一真实候选人上复测，构建并同步用户加载目录。

## 完成标准

截图中求职期望的城市、职位和薪资与页面一致；求职状态正确显示；不将已结束实习当作当前公司，不把期望城市代填当前城市。

## 完成结果与验证

- 根因：推荐卡 viewExpect.interestCityExpect=true 被解释为整组推荐方向，清空了全部 expected_*；列表 applyStatusDesc 为空，详情 Canvas 的状态没有进入结构化字段。另一个解析缺陷是把字体 `600 14px ...` 中的字重 600 当作字号，导致标签与值粘连。
- 修正：按 Canvas 行坐标与列间距识别明确的“求职期望”标签，优先补入期望城市、职位、薪资与头部状态，并附 Canvas 字段证据。仅移除与明确期望完全相同的推断方向；最近关注仍独立保留。使用 px 字号处理粗体和像素比例，空结果不覆盖已有字段。
- 后台页面会暂停绘制，实测得到 visibilityState=hidden、glyphs=0。新增 PAGE_NOT_VISIBLE，提示恢复浏览器，不再在此条件下返回缺少详情的采集结果。
- 当前截图对应候选人实测核对通过：测试 / 无锡 / 5-8K / 离校-随时到岗；没有错误的 recent_interest，没有虚构当前公司或当前城市；保留 1 段工作职责和 1 段教育说明，原文 1196 字符，1139 个绘制字形。
- 为恢复后台调试页面的真实绘制，验证期间临时启用 CDP Focus Emulation，结束后已关闭。关闭后确认隐藏页面读取返回 PAGE_NOT_VISIBLE。没有修改页面数据或构造 API 返回值；本次未验证用户重新加载后的原生扩展弹窗端到端操作。
- 14 项现有 Node 检查通过，新增覆盖粗体标签、2 倍像素比例、最近关注隔离及空头部；类型检查、生产构建和 v0.2.1 打包通过。release 散装目录同步新版，ZIP 14 个文件逐项 CRC 与内容核验通过。
- 边界：截图中的实习已结束，不能填为当前公司；期望城市不等于当前所在地。图片、附件和折叠文字的原有限制仍在。真实候选人数据仅在浏览器内存核验，临时核验全局变量已删除，未写入项目或安装包。
