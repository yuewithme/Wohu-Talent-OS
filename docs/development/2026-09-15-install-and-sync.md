# 安装后自动同步，无需填写连接信息

## 任务目标

按用户最新确认，内部插件安装后，登录并打开 BOSS 即自动扫描所有可访问会话的新附件及历史附件，无需填写地址、访问凭证或开启开关。

## 实施计划

1. 生成内部预配置安装包：打包时从本机配置读取同步凭证，仅写入插件后台产物，不写入公开源码、页面采集脚本或飞书应用密钥。
2. 默认启用扫描及历史补录，首次升级自动迁移旧设置，之后保留用户主动暂停状态；固定现有 18083 入口，移除使用者连接表单。
3. 用独立全新浏览器配置验证免设置安装、启动闹钟、自动建立 BOSS 消息标签页和服务访问；在已登录 Edge 验证真实附件及去重，核对安装包及 Git 数据。
4. 更新 v0.3.2 安装包、使用说明与开发日志，提交功能分支并推送 main。

补充：用户要求登录时只打开一个 BOSS 页面。同步标签页需按浏览器会话保存 ID，登录跳转时继续复用；已有消息页直接使用，避免未登录时每轮生成新标签页。登录准备期间暂时暂停扫描，实测完成后恢复。

## 完成标准

新安装无需任何设置，打开已登录 BOSS 后自动扫描并归档；同一附件不重复建档。重启或升级不会解除用户在新版主动选择的暂停。公开仓库无实际服务凭证或简历，内部安装包不包含飞书 App Secret。

## 完成结果与验证

已完成 v0.3.2 的免配置安装与真实归档验证。服务端现有 Bearer 校验保留，使用者无需手动配置。内部包携带同步服务的客户端凭证，持有包的人可提取该凭证，因此仅内部交付，不作为公开 Release 附件；无需新增公开注册接口。仍使用用户指定的 HTTP 18083 入口。

- 构建：从环境变量或忽略 Git 的 `server/.env` 读取客户端凭证，仅注入后台脚本。缺少有效配置时拒绝构建，公开源码不保留实际值。
- 启动：全新安装默认启用自动同步和历史补录，不自动打开设置表单。旧版设置仅迁移一次，之后保留用户主动暂停状态。接口只接受两个偏好开关，拒绝外部传入接收地址或凭证。
- 单页：复用已打开的 BOSS 消息页；未登录时等待。需要创建后台消息页时在会话存储中保存其 ID，登录跳转后继续复用，避免反复打开标签页。
- 实际 Edge：用户登录后，通过内置连接完成 5 个会话扫描、2 份附件重新归档，状态均为 done、无错误，浏览器仅有 1 个 BOSS 标签页。服务端仍只有 2 条 done 任务，未重复建档。登录准备时的临时暂停已恢复。
- 全新 Chromium 配置：未填写任何信息，自动同步、历史补录及 30 秒闹钟均启用；未自动打开设置页。设置页只剩两个复选框，扩展存储未保存凭证明文。未登录 BOSS 时返回 WAITING_BOSS_LOGIN，多轮观察始终只有 1 个 BOSS 页面。
- 偏好验证：主动暂停后关闭并重新启动独立浏览器，暂停仍保留、无扫描闹钟；恢复时内置连接的服务校验成功。尝试通过偏好接口修改服务地址及凭证被拒绝。
