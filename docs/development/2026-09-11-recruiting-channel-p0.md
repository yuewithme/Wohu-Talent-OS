# Recruiting Channel Adapter 浏览器插件开发日志

## 任务目标

依据用户提供的《Recruiting_Channel_Adapter_开发设计_v0.2_完整表版.md》，从空目录开发 Chrome MV3 浏览器插件，完成插件端 BOSS 当前候选人读取、选岗、去重预览、人工确认、提交与同步状态展示，并按文档契约调用已有/未来后端。用户最终明确：浏览器插件是本次目标边界，不开发后端、数据库或飞书同步服务。设计文档是需求依据，其中未实测的页面选择器、身份稳定性和待决策配置不能当作已验证事实。

## 实施计划

1. 固定插件 TypeScript 数据契约、消息协议和接口校验，搭建 React + MV3。
2. 实现最小权限、后台 API 通信、后端连接与登录配置、页面读取、岗位选择、重复审查、提交恢复及脱敏诊断。
3. 实现 DOM Adapter 与实测选择器配置；只读取可见 DOM 文字，不读取完整图片简历、页面运行态或私有接口；外部 ID 默认不作强身份。
4. 实现候选人字段与经历预览、缺失提示、状态机和异常恢复；飞书仅展示后端返回的同步结果。
5. 运行类型检查、构建和必要的针对性验证；浏览器安装/交互检查；交付加载目录、安装包与使用说明。

## 完成标准

- 构建产物可作为未打包 Chrome/Edge 扩展加载。
- 插件读取与提交分离；Preview/Commit 使用文档接口；提交重试沿用相同幂等键。
- 疑似重复必须明确决策；明确重复不提供新建动作；尊重后端允许动作与权限。
- Token 只保存在插件会话存储，不进入页面；只向用户授权的后端发送数据；诊断不含候选人明文。
- Popup 关闭或后台唤醒后能查询已提交导入的状态；展示飞书同步中/成功/失败。
- 真实 BOSS 页面采集需实际页面/脱敏样本；端到端导入需可用后端。未经联调不声称达到文档准确率或后端验收目标。

## 已确认与待补充

- 最终范围：仅浏览器插件，后端及飞书服务不实施。
- 从空目录开始，使用 Node 24、npm 11 完成开发。
- 暂按文档默认：Preview 有效期使用后端返回值或 30 分钟，合并策略为内部人工确认字段优先。
- 已获得用户授权的真实 BOSS 登录页面并完成 DOM 实测。后端 URL/组织 ID/登录凭证尚未提供，后端联调留待接入时执行；飞书 Base 与密钥不属于插件配置。
- 发布先交付本地加载包；线上域名、认证接入和商店发布待实际环境确定。

## 完成结果

- 已实现 MV3 基础、React 弹窗/设置页、严格接口契约、后台消息校验、按域授权、会话 Token、预览/确认交互、同幂等键重试、提交状态恢复与脱敏诊断。
- 真实页面 POC：BOSS `/web/chat/recommend` → `/web/frame/recommend/` → `/web/frame/c-resume/`；完整简历位于 `canvas#resume`，右侧 `.resume-summary` 提供经历摘要。不存在可用于完整正文的 DOM 文本。
- 用户最终明确只需读取 DOM 文字。最终实现采集可见经历摘要、结构化工作/教育条目和 DOM 原文；没有 OCR、图片识别、完整正文抓取及对应依赖。
- 当前详情 DOM 不含姓名，因此本地预览保留缺失；仅在导入前由用户补充姓名，后端 Preview 仍严格拒绝空姓名。
- 已交付 `dist/` 可加载目录、`release/wohu-talent-0.1.0.zip` 分发包及 README 安装/运行说明。浏览器插件开发目标已完成，后端及飞书服务不在本次范围内。

## 验证情况

- `npm run check`：TypeScript 校验及生产构建通过。
- `npm test`：9 项必要的纯逻辑/契约校验通过，包括本地缺失姓名可预览、后端契约禁止空姓名；使用 Node 内置测试运行器，无新增测试框架、Mock 或 Fixture。
- 独立 Chromium 151 环境：未打包扩展加载成功，Manifest 无警告/错误；真实扩展页面脚本无异常，弹窗及设置页无横向溢出。
- 真实 BOSS DOM：两份候选人分别读取 1 段工作/1 段教育、4 段工作/1 段教育；公司与学校逐项对照 DOM 一致，selector miss 为 0；姓名、电话、邮箱、外部 ID 缺失时均保持为空。
- SPA 切换：两份不同摘要产生不同指纹；隐藏的旧推荐 iframe 不参与读取。关闭详情后的 `v-leave` 过渡节点被排除，返回 `UNSUPPORTED_PAGE`。
- 分发包：ZIP CRC 校验通过，包含 13 个文件，Manifest V3 权限与交付目录一致；不含图片识别文件或依赖。
- 真实 API 联调尚未执行，因为用户未提供后端；统计准确率、全页面覆盖、后端幂等和飞书实写不属于本次已验证结果。
