# 沃虎人才 · 简历自动归档

Chrome / Edge MV3 插件与统一同步服务。配置后，打开 BOSS 招聘端会自动建立后台消息标签页，每 30 秒扫描可访问会话中的入站附件简历，上传至管理员指定的飞书多维表格。

## 使用者安装

1. 解压 `release/wohu-talent-0.3.0.zip`。
2. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载解压后包含 `manifest.json` 的目录。
3. 打开插件的「同步设置」，填写管理员提供的 HTTPS 服务地址与访问凭证，启用自动同步和历史附件。
4. 保持 BOSS 已登录，允许插件创建的后台消息标签页保持打开。插件弹窗显示归档数、扫描进度、失败原因和飞书记录链接。

更新已有插件时覆盖原加载目录中的文件，然后在扩展管理页点击「重新加载」。使用者电脑无需安装 Node、SSH 或飞书连接器。

## 当前范围

- 读取 BOSS 当前账号开放的联系人和会话历史；平台联系人列表可能仅开放近 30 天，无法补录未暴露或已失去访问权限的更早联系人。
- 只归档候选人已发送的附件简历；在线微简历卡片不作为文件。不会发送聊天消息或主动索要简历。
- 支持 PDF、DOC、DOCX、RTF、TXT、PNG、JPG，单份最大 20 MB。下载过期、无权限或文件类型不符时保留失败任务。
- 浏览器按账号、候选人、消息和附件标识去重；服务端按账号、候选人和文件 SHA256 去重，同一账号在多台电脑重复提交不会新建相同记录。不同 BOSS 账号的归档彼此独立。
- 暂停停止接收新任务，已提交给服务端的任务继续处理。更换目标服务前须处理完待办任务。

## 管理员部署

服务使用 Node.js 24、SQLite 和飞书应用身份。单实例部署，SQLite 及待上传文件使用持久卷；文件成功归档后删除服务端暂存副本。飞书记录、任务元数据及去重键保留。

1. 复制 `server/.env.example` 为 `server/.env`，填写飞书应用、目标 Base / Table、完整 Base URL，以及至少 32 字符的随机 `SYNC_ACCESS_TOKEN`。密钥文件不提交 Git。
2. 为飞书应用开通多维表格读写、素材上传权限并发布生效；将应用添加为目标表的可编辑协作者。
3. 目标表需要下列字段。文本字段类型为「多行文本」，日期为「日期」，附件为「附件」。

| 字段 | 类型 |
|---|---|
| 候选人、同步键、沟通职位、BOSS账号、候选人标识、消息标识、原文件名、文件SHA256 | 文本 |
| 接收时间 | 日期 |
| 简历附件 | 附件 |

4. 执行 `docker compose up -d --build`。服务仅绑定服务器 `127.0.0.1:18084`，数据保存在 `resume-data` 卷。
5. 为独立域名配置 HTTPS 反向代理到 `127.0.0.1:18084`，请求体限制至少 30 MB，读写超时至少 60 秒。不要把访问凭证放入 URL。
6. 验证 `/healthz`，再使用访问凭证验证 `/v1/status`；后者检查应用授权和目标字段。

| 接口 | 用途 |
|---|---|
| `GET /healthz` | 进程健康，不要求认证 |
| `GET /v1/status` | 应用与表结构验证 |
| `POST /v1/resumes` | 接收附件原始字节的 Base64 与必要元数据 |
| `GET /v1/resumes/{key}` | 查询处理结果 |
| `POST /v1/resumes/{key}/retry` | 重试已阻断任务 |

除健康检查外均要求 `Authorization: Bearer <SYNC_ACCESS_TOKEN>`。服务端自动重试最多 6 次，失败后等待人工重试。重启保留队列，并先在飞书查重再恢复写入。

## 数据存放

BOSS 登录和附件下载在使用者浏览器完成，Cookie、页面授权参数及下载 URL 不上传服务器。服务仅收到附件字节、候选人姓名、沟通职位、接收时间和去重所需标识。飞书 App Secret 仅保留在服务端配置。

扩展访问凭证、扫描游标和任务元数据保存于本机扩展存储，网页内容脚本不能读取该存储。附件字节只在下载上传期间驻留内存。历史任务使用 `unlimitedStorage` 避免大量归档超过 Chrome 默认配额。

## 开发与验证

```powershell
npm ci
npm run check
npm test
npm run package
node --env-file=server/.env --import tsx server/index.ts
```

开发使用 Node.js 24+。本地联调允许 `http://127.0.0.1:8787`，其他电脑正式使用 HTTPS 服务地址。已有 v0.2.1 候选人手动读取基线保存在同名 Git 标签；当前交付入口为消息附件自动归档。

真实联调结果、限制与尚未完成项见 `docs/development/2026-09-14-resume-auto-sync.md`。构建通过不代表已通过真实附件到飞书的全链路验收。
